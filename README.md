# Dextra Sinistra

Ejercicios de guitarra para mano derecha (Dextra), mano izquierda (Sinistra) y ambas manos, con metrónomo, reloj y registro de progreso.

App web instalable (PWA): se abre a pantalla completa y funciona sin conexión.
